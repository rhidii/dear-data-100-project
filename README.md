# dear-data-100-project
dear data 100 project

ABOUT THE PROJECT:

For this project, I want to visualise my personal workout in a way that connects the data to the human body. I'll be saving my workout history to Hevy to then make my CSV file to create a visualisation showing the relationship between different muscle groups and the exercises I do.

Rather than using traditional graphs and charts, I want to represent my data through a visual network of the body, muscles and exercises. I also want to experiment with animation and sound to make the visualisation more interactive. 

VISUALISATION:

The visualisation will be structured around three main elements which are the body, individual muscles and exercises.

I'll use connections to show which exercises target which muscles. The primary muscle connection will be more prominent, whereas the secondary muscle connection will be less prominent. 

I want to use colour and pulse speed to represent different aspects of my workout data.

Colour will represent the absolute weight I've lifted, measured in kilograms. Pulse speed will represent my overall progression of my recorded weight over time with the pulse becoming faster as the weight I'm lifting increases. When my weight stays relatively stable, the pulse will remain slower. 

DATA:

I'll be using my workout history exported from Hevy. I'll process the data and organise it into a CSV file that can be used by the visualisation. 

The dataset will contain information about my workouts, exercises, weights and muscles associated with each exercise.

TECHNOLOGIES:

I'm planning to use processing with Java to create the visualisation, CSV files to store my data and sound to add another dimension to the experience. I'll also use Git and Github to manage the project and keep track of changes. (And also because it is a requirement)
